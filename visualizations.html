001 / METHOD

Generated, not designed.

Every visualization on this page is generated procedurally from the simulation engine. There are no mockups, no marketing renders, no Photoshopped diagrams. Each visualization is a real algorithm running on real parameters, captured as a PNG.

The generation pipeline is HTML + CSS + SVG + JavaScript, rendered headless via Playwright at 1920×800. Each visualization has a dark and light variant, adaptive to the viewer's theme. The source HTML files are in docs/viz/ — they are versioned, inspectable, and reproducible.

The visualization is not a picture of the system. The visualization is the system, rendered.
