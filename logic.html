Logic · How AEGIS Thinks

The intelligence,
made structural.

Six diagrams that decode how AEGIS turns raw sensor signals into classified threats. The pipeline, the algorithms, the state machines, the protocol sequences. No black boxes — every transformation is documented.

001 / PIPELINE

Signal to decision.

A raw sensor signal enters at the left. Six stages transform it. A classified threat with a confidence score exits at the right. Total median latency: 1124ms. Each stage is independent and modular.

The pipeline is deliberately linear. No stage can skip ahead. No stage can call back to a previous one. This is a design constraint, not a limitation — it means each stage can be optimized, swapped, or parallelized independently, without touching the others. The ESTIMATE stage (UKF) is the algorithmic bottleneck. The DETECT stage (CV + signal threshold) is the I/O bottleneck.

002 / ESTIMATION

UKF sigma point propagation.

The Unscented Kalman Filter does not linearize. It samples. Seven sigma points are drawn from the prior distribution, propagated through the nonlinear dynamics f(x), and the posterior is reconstructed from the transformed points.

The left ellipse is the prior — the current state estimate with its uncertainty. Seven points sample this distribution. Each point is pushed through f(x), the nonlinear dynamics function (in AEGIS, this is the 47→32→32→15 MLP). The points arrive at new positions, forming a new distribution — the posterior. The mean and covariance of the posterior are computed from the transformed points.

This is more accurate than the Extended Kalman Filter because it does not assume the dynamics are locally linear. A high-g maneuver — where the trajectory curves sharply — is exactly where linearization fails and sampling succeeds.

003 / CONSENSUS

BFT protocol sequence.

When sensors disagree, the Byzantine Fault Tolerant consensus protocol reconciles them. Three phases per round: pre-prepare (leader proposes), prepare (nodes verify), commit (nodes sign). Faulty nodes are detected and excluded.

The leader (rotating role) broadcasts a proposed state. Honest nodes verify the proposal against their own estimates. If a node's estimate diverges by more than 3σ, it is flagged. In the sequence above, NODE X (faulty) attempts to inject false data — its message is rejected by the honest nodes. After 20 rounds, 7 honest nodes have agreed, 3 faulty nodes are isolated.

The protocol overhead is fixed — it does not grow with target count, only with node count. This is why BFT scales: the consensus cost is O(N²) in messages but O(1) in target count.

004 / AGENTS

Agent behavior state machine.

Each of the 10,000 agents transitions between 9 behavioral states based on stress, trust, and macro indicators. Threshold crossings trigger transitions. When stress exceeds 0.7, political threat signals fire.

Agents start in NORMAL. As economic indicators degrade — unemployment rises, inflation spikes, debt crosses thresholds — stress accumulates. Agents move through ANXIOUS, PANICKING, SPECULATING. If conditions worsen, they enter BLACKMARKET or FLEEING. Beyond stress 0.7, they enter the unstable states: STRIKING, RIOTING, REBELLING.

The aggregation of these states across 10,000 agents produces the political threat signals: coup risk, civil war probability, revolution likelihood. A system with 30% of agents in unstable states is already in crisis — the math just makes it visible before the streets do.

005 / NONLINEAR

The 7-layer transform stack.

Between the neural network's linear output and the final indicator a policymaker reads, seven transformations sit. Each implements a documented phenomenon from complexity economics — debt cliffs, bifurcations, hysteresis, feedback loops, cascades, runaway, thermodynamic equilibrium.

Each layer has a threshold. Below the threshold, the layer is transparent — the signal passes through unchanged. Above the threshold, the layer transforms the signal non-linearly. Debt below 80% of GDP is just debt. Debt above 80% triggers exponential risk amplification. The system does not smooth over this discontinuity — it makes it visible.

The final layer — THERMODYNAMIC — is the system's anti-hubris mechanism. If you push too many levers to their maximum (over-optimization), the system penalizes itself. You cannot maximize one sector without paying for it elsewhere. This is not a bug. It is a design principle borrowed from physics.

006 / KERNEL

The 12-phase tick lifecycle.

Every 200ms, the Kernel runs 12 phases in sequence. Each phase transforms the system state. The total budget is 185ms, leaving 15ms headroom for jitter. SWARM (10,000 agent update) is the bottleneck at 45ms.

The Kernel is not a loop — it is an operating system. Subsystems register for phases. A syscall surface exposes read_state, set_lever, register_subsystem. The engine that does the work has a structure that can be reasoned about, extended, and observed.

The 15ms headroom is not slack — it is the system's immune system. If any phase overruns (a spike in target count, a cascade of black swan events), the headroom absorbs it. When the headroom is consumed, the system enters graceful degradation: non-critical phases are skipped, tick rate drops to 25Hz, and the operator is alerted.
