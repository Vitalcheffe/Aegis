Phase Portrait · Target Dynamics

Phase space of target position (x) vs velocity (ẋ) for the canonical engagement dynamics. Each cyan curve is a trajectory from a different initial condition. The amber dot at (80, 0) is the stable attractor — the intercept point where trajectories converge. The crimson marker at (-60, 0) is a saddle point — trajectories approach then diverge. The UKF must estimate which trajectory the target is on, given sparse sensor samples. Maneuvers appear as sudden jumps between trajectories in this phase space.
