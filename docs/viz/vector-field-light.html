Velocity Field · Drag Coefficient Gradient

Vector field of the velocity gradient ∇v around two singularities — a source (top-left) where flow diverges, and a sink (bottom-right) where flow converges. Vector color encodes magnitude: cyan = low velocity, amber = moderate, crimson = high. The mesh reveals the underlying aerodynamic structure that the UKF must estimate from sparse sensor samples. Singularities are mathematically the points where the Jacobian loses rank — detection of these points is how the system identifies maneuver onset.
