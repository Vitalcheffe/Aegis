Latency Breakdown by Phase · Stacked Bars

Each stacked bar shows the total response time for one target count scenario, broken down by pipeline phase. Perception (cyan) dominates at low target counts — sensor I/O is the bottleneck. Estimation (violet) grows with target count as the UKF processes more tracks. BFT consensus (emerald) stays roughly constant — the protocol overhead is fixed. Coordination (amber) grows non-linearly past 20 targets as the mesh protocol reorganizes. The 2000ms budget (crimson dashed) is exceeded at 25+ targets.
