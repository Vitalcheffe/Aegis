UKF Accuracy vs Target Count · Scalability

Root Mean Square estimation error as the number of simultaneous targets scales from 1 to 30. Below 15 targets (cyan), the system stays within the real-time budget (RMSE under 15m). Between 15 and 25 targets (amber), accuracy degrades gracefully. Above 25 (crimson), the 50Hz tick budget is exceeded and accuracy degrades non-linearly. This is a benchmark limit, not an algorithmic one — GPU acceleration would push the curve right.
