# AEGIS Defense Systems Documentation

## Project Overview

Autonomous drone swarm interceptor system designed to invert the air defense cost-curve.

### Key Features
- 50Hz hard-real-time logic
- UKF (Unscented Kalman Filter) state estimation
- BFT (Byzantine Fault Tolerant) sensor fusion
- Palantir-style B&W counter-UAS interface
